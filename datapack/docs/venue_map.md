## 判定區

| 判定區 | 定義 |
| --- | --- |
| 頭頂線 | 開場後滿座時，沿每一排坐著的人頭頂畫出的折線；投影幕與舞台面積扣掉 |
| 座位判定區 | 頭頂線以下的座位範圍，用來算 `occupied_ratio` |
| 舉起判定區 | 頭頂線以上的範圍，用來算 `raised_ratio` 與 `standing_ratio` |
