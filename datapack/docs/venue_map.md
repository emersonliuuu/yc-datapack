## 判定區

| 判定區 | 定義 |
| --- | --- |
| 座位區 | 上表各 zone 的座位範圍；`visible_count`、`seated_count`、`standing_count` 只算這個範圍內的人 |
| 走道 | 【範圍】；在走道上的人不算進任何一區 |
| 區的邊界 | 離席、回座以人跨過區的邊界判定：`left_count` 是從座位起身並走出區，`returned_count` 是走進區並坐下 |
| 舞台 | 舞台上的人不算觀眾 |
