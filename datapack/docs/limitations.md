# 量不到什麼

發布前依實際狀況更新；`manifest.csv` 標 `partial` 或 `not_available` 的檔案，原因都要寫在這裡。

## 刻意不收

| 不收 | 為什麼 |
| --- | --- |
| 影片、音檔、人臉 | 原始影音只留在辦公室本機，資料包只放文字與數字 |
| 觀眾姓名、聯絡方式、帳號 | 聯絡名單另存，不進資料包 |
| 骨架、細動作、個人軌跡 | 只做座位區面積法，不追個人 |
| 性別、年齡等外觀推論 | 推論不準，也碰到個資 |
| 簡報原檔與畫面 | 公開播送權；只放頁標題與我們的筆記 |
| Networking 群聚、飲食台 | 11/3 決定不做 |

## 量不準

| 項目 | 限制 |
| --- | --- |
| 舉起來 | 分不出手或手機；前排被前面的人擋住時會低估；鏡頭只看到部分座位區 |
| 人數 | 所有人數都是下限 |
| 全場安靜 | 只在有收音的位置判定，代表不了全場每個角落 |
| 講完被圍住 | 人工計數，只算手持鏡頭拍到的部分 |
| 公開貼文對到現場時刻 | 屬於推論，見 `social/post_to_moment.csv` 的 `match_confidence` |
