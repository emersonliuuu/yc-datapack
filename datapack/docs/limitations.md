# 量不到什麼

發布前依實際狀況更新；`manifest.csv` 標 `partial` 或 `not_available` 的檔案，原因都要寫在這裡。

## 刻意不收

| 不收 | 為什麼 |
| --- | --- |
| 影片、音檔、照片、3D 模型、人臉 | 原始影音只留在辦公室本機，資料包只放 CSV 與 Markdown；場景改用文字描述 |
| 觀眾姓名、聯絡方式、帳號 | 聯絡名單另存，不進資料包 |
| 人臉辨識、個人編號與軌跡 | 影像偵測只用來數人；前後畫面的比對只用來判斷動作持續幾秒，不保存也不輸出 |
| 性別、年齡等外觀推論 | 推論不準，也碰到個資 |
| 簡報原檔與畫面 | 公開播送權；只放頁標題與我們的筆記 |
| Networking 群聚、飲食台 | 11/3 決定不做 |

## 量不準

| 項目 | 限制 |
| --- | --- |
| 舉手、舉手機 | 只有一台 X5，背對或被前面的人擋住的會漏數；手機被手遮住時可能被當成舉手 |
| 人數 | 所有人數都是下限；只算 X5 看得到的座位區，範圍見 `docs/venue_map.md` |
| 離席、回座 | 只看跨過區的邊界；不追個人，同一人出去又回來會各算一次 |
| 全場安靜 | 只在有收音的位置判定，代表不了全場每個角落 |
| 講完被圍住 | 人工計數，只算手持鏡頭拍到的部分 |
| Wifi 人流 | 只有相對強弱與方向，不代表人數；`valid` 為 false 的時間窗不建議引用 |
| 公開貼文對到現場時刻 | 屬於推論，見 `social/post_to_moment.csv` 的 `match_confidence` |
